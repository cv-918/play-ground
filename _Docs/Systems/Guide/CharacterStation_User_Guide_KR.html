무엇을 하는 씬인가

CharacterStation은 플레이어 캐릭터와 적 캐릭터를 한 화면에서 고르고, 수치와 애니메이션을 조정하고, 현재 설정이 어떻게 보이는지 바로 확인하는 작업용 씬입니다.

목표는 게임을 직접 오래 플레이하지 않아도 캐릭터의 크기, 이동 범위, 공격 범위, 애니메이션 프레임, 적 투사체 발사 위치 같은 값을 빠르게 맞추는 것입니다.

이 문서는 사용자가 씬을 어떻게 쓰는지만 설명합니다. 파일 구조나 코드 구조를 몰라도 사용할 수 있도록 작성되어 있습니다.

할 수 있는 기능

캐릭터 선택과 편집

Playable 또는 Enemy 모드를 고르고, 목록에서 원하는 캐릭터를 선택해 이름, 체력, 몸 크기, 공격 속도 등을 조정할 수 있습니다.

미리보기

가운데 화면에서 선택한 캐릭터의 현재 모습과 애니메이션을 확인할 수 있습니다. 상태별 애니메이션도 골라볼 수 있습니다.

범위 가이드

몸체, 이동 발판, 시각 경계, 공격 범위, 수집 범위, 투사체 발사 위치, 프레임 경계를 켜고 끌 수 있습니다.

애니메이션 클립 관리

클립을 추가, 복제, 삭제하고 프레임 폴더, 파일 접두어, 시작/끝 프레임, FPS, 반복 여부를 조정할 수 있습니다.

리소스 시퀀스 선택

캐릭터 이미지 폴더에 있는 연속 프레임을 찾아 현재 클립에 바로 적용할 수 있습니다.

적 투사체 조정

적의 이동 방식, 투사체 사용 여부, 패턴, 발사 위치, 대미지, 속도, 사거리와 테스트 미리보기를 조정할 수 있습니다.

데이터 생성과 프리셋

새 플레이어 캐릭터, 새 적, 현재 캐릭터 복제본을 만들 수 있고 Balanced, Fast, Shooter, Tank 프리셋을 적용할 수 있습니다.

검사와 저장 보호

누락된 프레임, 잘못된 수치, 중복 이름 등을 확인하고, 저장하지 않은 변경이 있을 때 실수로 나가는 것을 막아줍니다.

들어가기와 화면 구성

씬 들어가기

  1. 게임을 실행합니다.
  2. Intro 화면에서 CharacterStation 버튼을 선택합니다.
  3. 오른쪽 또는 별도 DebugAssistant 창에 CharacterStation / Character 항목이 보이면 준비된 상태입니다.
CharacterStation은 작업용 씬입니다. 실행 환경에 따라 일반 플레이용 빌드에서는 보이지 않을 수 있습니다.

화면에서 보는 것

영역 의미
중앙 미리보기 현재 선택한 캐릭터, 애니메이션, 범위 가이드를 보여줍니다.
상단 상태 문구 저장 여부, 선택 상태, 최근 작업 결과, 경고 메시지를 보여줍니다.
DebugAssistant 창 캐릭터 선택, 수치 조절, 클립 편집, 저장 버튼이 모여 있는 작업 패널입니다.

단축키

키 동작
Esc Intro 화면으로 돌아갑니다. 저장하지 않은 변경이 있으면 한 번 더 눌러야 나갑니다.
F5 캐릭터 데이터를 다시 불러옵니다. 저장하지 않은 변경이 있으면 한 번 더 눌러야 버리고 불러옵니다.
F9 현재 모드의 데이터를 저장합니다. Playable 모드면 Playable만, Enemy 모드면 Enemy만 저장합니다.

기본 사용 흐름

  1. Mode에서 Playable 또는 Enemy를 고릅니다.
  2. Character 목록에서 작업할 캐릭터를 선택합니다.
  3. 중앙 미리보기와 Preview resource 문구로 이미지가 정상적으로 잡혔는지 확인합니다.
  4. 필요한 수치나 애니메이션 클립 값을 조정합니다.
  5. Validation과 Frames 문구가 빨간색 경고를 내는지 확인합니다.
  6. 결과가 괜찮으면 Save Current 또는 Save All로 저장합니다.
  7. 실제 게임 씬에서 움직임, 충돌, 공격감이 원하는 대로 나오는지 확인합니다.

DebugAssistant 항목 설명

항목 할 수 있는 일 언제 쓰나
Mode Playable과 Enemy 작업 대상을 전환합니다. 플레이어 캐릭터와 적 데이터를 번갈아 조정할 때 사용합니다.
Character 현재 모드의 캐릭터 목록에서 하나를 선택합니다. 특정 캐릭터의 수치나 애니메이션을 고칠 때 사용합니다.
Common Data 이름, 몸 크기, 체력, 접촉 대미지, 공격 속도를 조정합니다. 캐릭터의 기본 체급과 전투 기본값을 맞출 때 사용합니다.
Navigation / Bounds 이동 기준, 발판 크기, 발판 위치, 시각 경계를 조정합니다. 캐릭터가 벽이나 통로에서 어색하게 걸리거나, 보이는 크기와 충돌 느낌이 다를 때 사용합니다.
Playable Only 플레이어 공격 범위, 수집 범위, 이동 속도, 가속, 마찰을 조정합니다. 플레이어 조작감과 성장 전 기본 감각을 맞출 때 사용합니다.
Animation Clip 상태별 애니메이션과 프레임 정보를 편집합니다. 새 스프라이트 시퀀스를 연결하거나 프레임 속도를 맞출 때 사용합니다.
Enemy Projectile 적 이동 방식, 투사체 사용, 발사 위치, 대미지, 속도, 사거리를 조정합니다. 원거리 공격 적을 만들거나 투사체 발사 위치를 맞출 때 사용합니다.
Preview Guides 미리보기 위에 보조선을 켜고 끕니다. 보이는 이미지와 실제 판정 범위를 비교할 때 사용합니다.
Data Actions 새 데이터 생성, 복제, 되돌리기, 저장, 다시 불러오기를 실행합니다. 작업 단위를 만들거나 실수한 변경을 되돌릴 때 사용합니다.

애니메이션 설정

상태별 미리보기

Preview State에서 상태를 고르면 해당 이름의 애니메이션 클립을 찾아 미리보기에 표시합니다. Playable은 idle, move, attack, spell, hit, death 계열을 확인할 수 있고, Enemy는 spawn, idle, move, hit, attack, death 계열을 확인할 수 있습니다.

원하는 상태가 없거나 클립 이름이 맞지 않으면 경고 문구가 뜹니다. 이때는 Clips 목록에서 클립 이름을 확인하세요.

클립 편집

항목 의미
Clip Name 상태를 찾을 때 쓰는 이름입니다. 예: idle, move, attack.
Directory 이미지 프레임들이 들어 있는 폴더입니다.
Prefix 프레임 파일 이름에서 번호 앞에 붙는 공통 이름입니다.
Start, End 사용할 시작 프레임 번호와 끝 프레임 번호입니다.
FPS 애니메이션 재생 속도입니다. 높을수록 빠르게 재생됩니다.
Loop 끝까지 재생한 뒤 처음으로 돌아갈지 정합니다.
Preview Anim 미리보기 애니메이션을 재생하거나 멈춥니다.

리소스 시퀀스 적용

Resource Seq는 캐릭터 리소스 폴더에서 발견한 프레임 묶음을 보여주는 목록입니다. 후보가 많을 때는 Res Filter에 dust hit, lv4 attack처럼 단어를 입력해 원하는 후보만 좁혀서 볼 수 있습니다. Current Only를 켜면 현재 선택한 캐릭터 이름과 맞는 리소스만 우선 표시합니다.

  1. Res Filter에 캐릭터 이름, 동작 이름, 폴더 이름 일부를 입력합니다.
  2. 필요하면 Current Only를 켭니다.
  3. Prev Res, Next Res로 후보 페이지를 이동합니다.
  4. Resource Seq 목록에서 원하는 이미지 묶음을 선택합니다.
  5. Apply Res를 누릅니다.
  6. Directory, Prefix, Start, End, Clip Name이 자동으로 채워지는지 확인합니다.
  7. 후보 라벨과 Frames 문구에서 OK 또는 missing=0인지 확인합니다.
단일 프레임 후보는 single로 표시됩니다. 예를 들어 hit처럼 1장짜리 애니메이션도 정상 후보로 선택할 수 있습니다. 새 애니메이션을 연결할 때는 직접 경로를 타이핑하기보다 Res Filter, Resource Seq, Apply Res 순서로 작업하는 편이 안전합니다.

적 투사체 미리보기

Enemy 모드에서는 원거리 공격 적의 투사체 설정을 조정할 수 있습니다. Projectile Ability를 켜고 Pattern을 고른 뒤, Muzzle, Proj Dmg, Proj Speed, Atk Range를 맞춥니다.

항목 의미
Muzzle 캐릭터 기준 투사체가 시작되는 위치입니다. 미리보기에서 Muzzle 가이드를 켜고 조정하면 보기 쉽습니다.
Projectile Test 미리보기 화면에서 투사체가 사거리 방향으로 움직이는 모습을 간단히 보여줍니다.
Atk Range 투사체 테스트와 공격 범위 가이드에서 기준 거리로 사용됩니다.
Projectile Test는 작업용 시각화입니다. 실제 전투에서의 충돌, 타이밍, 난이도는 스테이지에서 별도로 확인해야 합니다.

저장, 되돌리기, 다시 불러오기

버튼 동작
Save Current 현재 선택한 모드의 데이터를 저장합니다. Playable 모드면 Playable만, Enemy 모드면 Enemy만 저장합니다.
Save All Playable과 Enemy 데이터를 모두 저장합니다.
Reload 저장된 데이터를 다시 불러옵니다. 저장하지 않은 변경이 있으면 한 번 더 눌러야 진행됩니다.
Revert Cur 현재 선택한 캐릭터만 마지막으로 불러온 상태 또는 마지막 저장 상태로 되돌립니다.
Revert Mode 현재 모드 전체를 마지막으로 불러온 상태 또는 마지막 저장 상태로 되돌립니다.
New Playable, New Enemy 새 플레이어 캐릭터 또는 새 적 데이터를 만듭니다.
Dup New 현재 선택한 캐릭터를 새 ID로 복제합니다.
Reset Anim 미리보기 애니메이션을 첫 프레임부터 다시 재생합니다.

Dirty 표시 읽는 법

Dirty는 저장하지 않은 변경이 있는지를 알려줍니다. Playable=yes면 Playable 데이터에 저장되지 않은 변경이 있고, Enemy=yes면 Enemy 데이터에 저장되지 않은 변경이 있습니다. Current=yes는 지금 선택 중인 캐릭터가 마지막 저장 또는 불러오기 이후 바뀌었다는 뜻입니다.

Dirty가 yes인 상태에서 저장하지 않고 나가거나 Reload를 두 번 누르면 변경 내용이 사라질 수 있습니다.

검사와 문제 해결

검사에서 확인하는 것

  • 이름이 비어 있지 않은지
  • 몸 크기 같은 기본 수치가 올바른지
  • 클립 이름이 비어 있거나 중복되지 않았는지
  • 프레임 시작/끝 번호와 FPS가 올바른지
  • 클립이 가리키는 이미지 프레임이 실제로 있는지
  • 투사체를 쓰는 적에게 패턴과 속도가 맞게 설정되어 있는지
  • ID가 중복되지 않았는지

자주 보는 상황

상황 확인할 것
미리보기에 이미지가 안 보임 Preview resource와 Frames 문구를 확인하고, Resource Seq로 다시 적용해 봅니다.
상태 미리보기가 안 바뀜 Clip Name이 상태 이름과 맞는지 확인합니다. 예: idle, move, attack.
Reload가 바로 안 됨 저장하지 않은 변경이 있어서 보호 중인 상태입니다. 정말 버릴 때만 Reload를 한 번 더 누릅니다.
Esc로 바로 나가지 않음 저장하지 않은 변경이 있어서 보호 중인 상태입니다. 저장하거나, 정말 버릴 때만 Esc를 한 번 더 누릅니다.
투사체 테스트가 보이지 않음 Enemy 모드인지, Projectile Ability가 켜져 있는지, Pattern이 Undefined가 아닌지 확인합니다.

추천 작업 흐름

기존 캐릭터 수치 조정

  1. Mode와 Character를 고릅니다.
  2. Body, HP, 이동 관련 수치를 조정합니다.
  3. 필요한 Preview Guide를 켜서 보이는 크기와 판정 크기를 비교합니다.
  4. Validation이 OK인지 확인합니다.
  5. Save Current를 누릅니다.

새 애니메이션 연결

  1. Clips에서 기존 클립을 고르거나 Add Clip을 누릅니다.
  2. Res Filter에 캐릭터 이름이나 동작 이름을 입력합니다.
  3. Resource Seq에서 원하는 프레임 묶음을 선택합니다. 보이지 않으면 Prev Res, Next Res로 페이지를 이동합니다.
  4. Apply Res를 누릅니다.
  5. Clip Name, FPS, Loop를 원하는 값으로 맞춥니다.
  6. Preview State와 Preview Anim으로 재생을 확인합니다.
  7. Frames가 missing=0인지 확인한 뒤 저장합니다.

새 적 만들기

  1. Mode를 Enemy로 바꿉니다.
  2. New Enemy 또는 Dup New를 누릅니다.
  3. 이름, 몸 크기, HP, 이동 방식, 공격 관련 수치를 정합니다.
  4. 필요하면 Shooter 또는 Tank 프리셋으로 시작점을 잡습니다.
  5. 애니메이션 클립과 투사체 설정을 확인합니다.
  6. Validation을 확인하고 Save Current 또는 Save All을 누릅니다.
작업 중 실험을 많이 할 때는 큰 변경 전에 Dup New로 복제본을 만든 뒤 조정하는 방식이 안전합니다.
