1. 도구 목적

이 도구는 PlayGround\Data 폴더의 현재 내용을 ZIP 파일로 묶은 뒤, 사용자의 Google Drive 폴더에 업로드합니다. 게임 데이터 JSON, 폰트, 이미지 리소스, Git에 아직 추적되지 않은 Data 하위 리소스도 실제 디스크에 있으면 함께 포함됩니다.

기본 결과물 이름은 PlayGround_Data_yyyyMMdd_HHmmss.zip 형식입니다. 실행할 때마다 새 스냅샷이 생성되므로 이전 백업을 보존하기 쉽습니다.

2. 파일 위치

구분 경로 설명
실행 파일 tools\google-drive-data-upload\upload_playground_data.bat 사용자가 실행하는 진입점입니다.
예시 설정 tools\google-drive-data-upload\config.example.json 로컬 설정 파일을 만들 때 복사해서 씁니다.
로컬 설정 _Local\GoogleDriveDataUpload\config.local.json Google Drive 폴더 ID와 옵션을 넣습니다. Git에 올리지 않습니다.
OAuth client _Local\GoogleDriveDataUpload\oauth_client.json Google Cloud Console에서 받은 Desktop OAuth client JSON입니다. Git에 올리지 않습니다.
OAuth token _Local\GoogleDriveDataUpload\token.json 최초 로그인 후 자동 생성됩니다. Git에 올리지 않습니다.
ZIP/로그 _Temp\GoogleDriveDataUpload\ 임시 ZIP과 업로드 로그가 생성됩니다. Git에 올리지 않습니다.

3. Google Drive 준비

  1. Google Drive에서 백업을 저장할 폴더를 하나 만듭니다.
  2. 브라우저 주소창에서 폴더 ID를 확인합니다. 보통 folders/ 뒤의 긴 문자열입니다.
  3. Google Cloud Console에서 프로젝트를 만들고 Google Drive API를 활성화합니다. 공식 문서: Google Drive API Node.js quickstart
  4. OAuth consent screen을 설정합니다. 개인용 테스트라면 테스트 사용자에 본인 Google 계정을 추가합니다.
  5. OAuth client ID를 만들 때 Application type은 Desktop app으로 선택합니다.
  6. 받은 JSON 파일을 _Local\GoogleDriveDataUpload\oauth_client.json에 둡니다.
OAuth client JSON과 token JSON은 인증 정보입니다. 문서, Dev Log, Git commit, 채팅에 내용을 붙여넣지 마세요.

4. 로컬 설정 만들기

저장소 루트에서 다음 폴더를 준비합니다.

mkdir _Local\GoogleDriveDataUpload

예시 설정을 로컬 설정으로 복사합니다.

copy tools\google-drive-data-upload\config.example.json _Local\GoogleDriveDataUpload\config.local.json

_Local\GoogleDriveDataUpload\config.local.json을 열고 drive_folder_id를 본인의 Google Drive 폴더 ID로 바꿉니다.

{
  "drive_folder_id": "여기에_구글드라이브_폴더_ID",
  "source_dir": "PlayGround\\Data",
  "archive_name_prefix": "PlayGround_Data",
  "keep_local_archive": false
}
필드 의미
drive_folder_id 업로드 대상 Google Drive 폴더 ID입니다. 필수입니다.
source_dir ZIP으로 묶을 데이터 폴더입니다. 기본값은 PlayGround\Data입니다.
archive_name_prefix ZIP 파일명 앞부분입니다. 기본값은 PlayGround_Data입니다.
keep_local_archive true면 업로드 성공 후에도 로컬 ZIP을 남깁니다. false면 성공 후 삭제합니다.

5. 실행 방법

5.1 사전 확인

업로드 없이 대상 파일 수와 생성될 ZIP 경로만 확인합니다.

tools\google-drive-data-upload\upload_playground_data.bat --dry-run

5.2 최초 업로드

처음 실행하면 브라우저가 열리고 Google 로그인/동의 화면이 나옵니다.

tools\google-drive-data-upload\upload_playground_data.bat --keep-archive

인증이 끝나면 _Local\GoogleDriveDataUpload\token.json이 생성됩니다. 이후 실행부터는 브라우저 인증 없이 업로드될 수 있습니다.

5.3 일반 업로드

설정의 keep_local_archive가 false면 업로드 성공 후 로컬 ZIP은 자동 삭제됩니다.

tools\google-drive-data-upload\upload_playground_data.bat

5.4 다른 설정 파일 사용

tools\google-drive-data-upload\upload_playground_data.bat --config _Local\GoogleDriveDataUpload\config.local.json

6. 팀원 배포 데이터 발행

팀원 게임 실행 시 자동으로 내려받을 최신 Data를 발행하려면 --publish-team-data 옵션을 사용합니다. 이 모드는 Google Drive에 PlayGround_Data_Latest.zip과 PlayGround_Data_Manifest.json을 고정 이름으로 유지하고, 실행할 때마다 파일 내용만 갱신합니다. 

tools\google-drive-data-upload\upload_playground_data.bat --publish-team-data --data-version 2026.05.15.001

팀원 배포 ZIP에서는 기본적으로 Data/UserData.json을 제외합니다. 팀원 로컬 세이브는 게임 실행 폴더의 기존 Data\UserData.json을 보존합니다.

옵션 의미
--publish-team-data 최신 배포 ZIP과 manifest를 만들고 Google Drive의 고정 파일을 생성 또는 갱신합니다.
--data-version 값 manifest의 data_version입니다. 같은 버전과 SHA256이면 게임 시작 시 다운로드를 생략합니다.
--dry-run 업로드 없이 파일 수와 생성될 경로만 확인합니다.
발행 성공 후 콘솔의 Manifest URL을 복사해 배포 폴더의 DataUpdateConfig.json에 넣습니다. Google Drive 파일은 팀원이 인증 없이 받을 수 있도록 anyone reader 권한으로 설정됩니다.

7. 결과 확인

  1. 콘솔에 Google Drive upload complete.가 출력됐는지 확인합니다.
  2. 콘솔에 표시된 File ID, File name, Link를 확인합니다.
  3. Google Drive 대상 폴더에서 PlayGround_Data_yyyyMMdd_HHmmss.zip 파일이 보이는지 확인합니다.
  4. ZIP을 열어 Data/UserData.json, JSON 데이터, Data/Resources/... 리소스가 들어있는지 확인합니다.
  5. 업로드 로그는 _Temp\GoogleDriveDataUpload\logs\ 아래의 upload_*.json 파일에서 확인합니다.

8. 게임 자동 갱신 설정

빌드하면 DataUpdater\apply_data_update.ps1과 DataUpdater\download_manifest.ps1이 exe와 같은 출력 폴더로 복사됩니다. DataUpdateConfig.json은 출력 폴더에 없을 때만 기본값으로 생성됩니다. 팀원에게 배포할 폴더의 DataUpdateConfig.json을 열어 자동 갱신을 켜면, 이후 빌드가 그 설정을 덮어쓰지 않습니다. 

{
  "schema_version": 1,
  "enabled": true,
  "manifest_url": "여기에_Manifest_URL",
  "timeout_seconds": 15,
  "failure_policy": "run_existing_data"
}

게임은 시작 직후 Data\DataUpdateManifest.json과 원격 manifest를 비교합니다. 이미 같은 data_version과 archive_sha256이면 다운로드 없이 바로 실행합니다. 새 데이터면 ZIP 다운로드, SHA256 검증, 압축 해제, 기존 Data 백업, Data 교체를 PowerShell helper로 수행합니다.

업데이트 진행 상황과 실패 원인은 exe 폴더의 _DataUpdate\data_update_service.log에 기록됩니다. 시작 전 별도 팝업은 띄우지 않습니다.

이번 실행에서 실제로 업데이트했는지, 이미 최신이라 생략했는지는 _DataUpdate\last_update_result.json에서 바로 확인할 수 있습니다.

SHIPPING이 아닌 Debug/Release 테스트 빌드에서는 게임 화면 우상단에도 약 8초 동안 Data updated, Data already latest, Data update failed 상태가 표시됩니다. 

{
  "schema_version": 1,
  "status": "updated",
  "checked_at_local": "2026-05-15T03:20:00",
  "data_version": "2026.05.15.001",
  "message": "Data update helper completed."
}
status 의미
updated 새 ZIP을 다운로드하고 Data 교체를 완료했습니다.
skipped_already_applied 로컬 manifest가 원격 manifest와 같아서 다운로드와 교체를 생략했습니다.
update_failed 업데이트 적용 중 실패했습니다. 게임은 기존 Data로 실행됩니다.
check_failed / manifest_invalid 원격 manifest 확인에 실패했습니다. 게임은 기존 Data로 실행됩니다.
disabled DataUpdateConfig.json에서 자동 갱신이 꺼져 있습니다.
업데이트 실패, 네트워크 실패, manifest 오류, SHA 불일치가 발생해도 게임은 기존 Data로 실행됩니다. 이 정책은 failure_policy의 기본값인 run_existing_data에 맞춘 동작입니다.

9. 문제 해결

오류 원인 해결
CONFIG_ERROR 로컬 설정 파일이 없거나 drive_folder_id가 비어 있습니다. _Local\GoogleDriveDataUpload\config.local.json을 만들고 폴더 ID를 입력합니다.
SOURCE_ERROR PlayGround\Data 폴더를 찾지 못했습니다. 저장소 루트에서 실행했는지, 설정의 source_dir가 맞는지 확인합니다.
ZIP_ERROR ZIP 생성 중 파일 접근 문제가 생겼습니다. 게임이나 이미지 편집기가 Data 파일을 잠그고 있지 않은지 확인한 뒤 다시 실행합니다.
AUTH_ERROR OAuth client JSON이 없거나 Google 인증이 실패했습니다. oauth_client.json 위치를 확인하고, 필요하면 token.json을 삭제한 뒤 다시 인증합니다.
EADDRINUSE 이전 인증 시도나 다른 프로그램이 로컬 OAuth 콜백 포트를 사용 중입니다. 최신 도구는 53682부터 53720까지 빈 포트를 자동으로 찾습니다. 계속 실패하면 이전 Node 프로세스를 종료한 뒤 다시 실행합니다.
UPLOAD_ERROR Drive 폴더 접근 권한, 폴더 ID, 네트워크, API 설정 문제일 수 있습니다. Google Drive API 활성화 여부, 폴더 ID, 계정 권한, 네트워크 상태를 확인합니다.
DOWNLOAD_ERROR 게임 실행 중 manifest의 download_url에서 ZIP을 받지 못했습니다. Drive 공개 권한, URL, 네트워크 상태를 확인합니다. 게임은 기존 Data로 계속 실행됩니다.
CHECKSUM_ERROR 다운로드한 ZIP의 크기나 SHA256이 manifest와 다릅니다. 배포 데이터를 다시 발행하고, manifest URL이 최신 파일을 가리키는지 확인합니다.
EXTRACT_ERROR / APPLY_ERROR 압축 해제나 Data 교체 중 문제가 발생했습니다. 게임 폴더 권한, 실행 중인 다른 프로세스의 파일 잠금, 디스크 여유 공간을 확인합니다.

10. 주의 사항

  • _Local, _Temp, node_modules, .env, OAuth 관련 JSON은 Git에 올리지 않습니다.
  • 이 도구는 PlayGround\Data를 수정하지 않습니다. 현재 디스크 상태를 읽어서 ZIP으로 묶습니다.
  • 업로드 성공은 Google Drive 폴더에서 직접 한 번 확인해야 합니다.
  • 다른 Google 계정으로 바꾸려면 _Local\GoogleDriveDataUpload\token.json을 삭제하고 다시 실행합니다.
  • Google Drive API와 OAuth 사용법은 Google 정책 변경에 영향을 받을 수 있으므로, 인증 문제가 계속되면 공식 문서를 확인합니다.
이 문서는 독립 로컬 도구 사용 가이드입니다. AIWorkflow Discord 명령, PC Runner, 승인 게이트, 완료/커밋 절차는 변경하지 않습니다.
