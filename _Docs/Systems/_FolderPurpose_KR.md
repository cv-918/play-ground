# 폴더 용도: Systems

## 목적

이 폴더는 구체적인 게임 시스템 문서를 보관한다.

개별 시스템이 어떻게 동작하는지, 데이터와 런타임 생명주기와 어떻게 상호작용하는지, 어떤 전제가 필요한지, 어떻게 검증해야 하는지를 설명하는 문서를 이 폴더에 둔다. 이 문서들은 게임 기획 문서보다는 구현에 가깝고, 넓은 아키텍처 문서보다는 특정 시스템에 집중해야 한다.

## 여기에 둘 문서

- Animation system 동작
- Rendering pipeline note
- Scene flow와 lifecycle 규칙
- Input, collision, UI, save/load, data loading 동작
- JSON 기반 시스템 동작과 validation note
- Component interaction 규칙
- Runtime order와 dependency note
- 시스템별 debug와 troubleshooting note

## 여기에 두지 않을 것

- 저장소 전체 workflow 규칙
- 상위 게임 기획 목표
- 여러 시스템에 걸친 일반 아키텍처 결정
- 완료된 FixLog
- 임시 조사 메모
- 소스 파일 또는 생성된 빌드 산출물
