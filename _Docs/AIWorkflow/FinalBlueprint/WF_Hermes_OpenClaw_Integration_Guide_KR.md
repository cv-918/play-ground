# Hermes / OpenClaw 연동 가이드

## 1. 목적

Hermes와 OpenClaw는 Studio를 대체하는 도구가 아니다.

두 도구는 Studio의 지시와 승인 아래에서 일하는 외부 직원 또는 장비 후보로 본다.

핵심은 이거다.

```text
Studio = 결정권
Hermes = 브라우저/웹 조사 장비
OpenClaw = 장기 실행 AI 직원 런타임 후보
```

## 2. 역할 요약

| 도구 | 역할 | 초기 권한 |
|---|---|---|
| Hermes | 웹 조사, 브라우저 QA, 화면/페이지 증거 수집 | 읽기, 확인, 캡처, 요약 |
| OpenClaw | 긴 조사, 여러 단계 분석, 직원 보고서 초안 | 읽기, 분석, 제안, 초안 |

둘 다 Studio가 승인한 Work Packet 안에서만 움직여야 한다.

## 3. Hermes를 쓰기 좋은 경우

Hermes는 브라우저가 필요한 작업에 적합하다.

예:

- 웹 조사
- 공식 문서 읽기
- 경쟁작/참고 페이지 확인
- 브라우저 UI QA
- 브라우저 게임 smoke check
- 스크린샷과 페이지 상태 수집
- 외부 AI 웹 UI 실험

Hermes 결과는 보통 아래 형태로 Studio에 들어와야 한다.

- 조사 노트
- 검증 자료 링크
- Wiki Inbox 항목
- 직원 보고서 입력
- 회의 참고 자료

Hermes가 하면 안 되는 것:

- 방향 승인
- 공식 설정 확정
- 로컬 소스 직접 수정
- commit/push
- 승인 없는 장시간 브라우저 작업

## 4. OpenClaw를 쓰기 좋은 경우

OpenClaw는 장기 실행 AI 직원 후보로 본다.

예:

- 오래 걸리는 조사
- 여러 단계 분석
- 직원 보고서 초안
- 여러 도구를 엮은 분석
- 제안 초안 생성
- Wiki 후보 생성

초기 모드는 이렇게 제한한다.

```text
읽기 / 분석 / 제안 / 초안 작성
```

OpenClaw가 하면 안 되는 것:

- 승인
- 공식 설정 직접 기록
- commit/push
- 제한 없는 로컬 제어
- 승인 범위 밖 파일 수정
- 최종 판단

## 5. 외부 도구 요청에 필요한 정보

외부 에이전트를 부를 때는 최소한 이것이 있어야 한다.

- 어떤 도구를 부르는지
- 왜 부르는지
- 어떤 안건 또는 Work Packet에 연결되는지
- 해도 되는 일
- 하면 안 되는 일
- 참고해야 할 맥락
- 기대 결과
- 필요한 검증 자료
- 중단 조건
- 비용 또는 외부 호출 위험
- 사람 승인이 필요한지

## 6. 결과물 기준

외부 도구가 단순 채팅만 남기면 안 된다.

Studio가 처리할 수 있는 형태로 돌아와야 한다.

- 조사 노트
- 직원 보고서
- 검증 자료 링크
- 제안 초안
- Wiki 후보
- 업무 후보
- 실패 보고서

## 7. 검증 자료 기준

외부 도구가 본 것과 한 일은 남아야 한다.

예:

- URL
- 접근 시각
- 스크린샷 경로
- 페이지 제목
- 참고한 문서 요약
- 로컬 파일 경로
- 명령 결과
- 실패 이유

이 자료는 “도구가 무엇을 봤는지”를 보여준다.

하지만 “결론이 맞다”는 뜻은 아니다. 결론은 Studio와 사람이 검토한다.

## 8. 반드시 사람이 판단해야 하는 것

아래는 Human Director 승인 없이 진행하면 안 된다.

- 방향 채택
- 공식 설정화
- 구현 착수
- 소스/데이터/설정 변경
- commit/push
- 추가 비용이 드는 외부 API 사용
- 장시간 자율 로컬 제어 허용

## 9. 추천 도입 순서

1. 도구 정책과 안전 경계를 문서화한다.
2. 읽기 전용 ToolRequest 기록부터 만든다.
3. Hermes/OpenClaw 결과를 수동으로 Wiki Inbox나 직원 보고서로 가져온다.
4. Studio 버튼은 먼저 요청 준비까지만 하게 한다.
5. 검증 자료와 중단 조건이 안정된 뒤 실행을 붙인다.
6. 여러 번 성공한 뒤에만 자동 라우팅을 검토한다.

## 10. 멈춰야 하는 상황

아래 상황이면 멈추고 사람 판단을 받아야 한다.

- 도구가 범위 확장을 요구함
- 비용이 발생할 수 있음
- 브라우저 로그인/개인 계정 접근이 필요함
- 소스/데이터/설정 수정이 필요함
- 검증 자료가 없음
- 기존 공식 설정이나 결정과 충돌함
- 출처를 설명하지 못함
