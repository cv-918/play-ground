# Studio Proposals

## Purpose

This folder stores governed `Proposal` records created by AI staff, meetings,
or the Human Director.

A proposal is not approval and is not canon.

Proposal records should make a possible direction reviewable by showing:

- what is suggested
- why it is useful
- options and tradeoffs
- risks
- dependencies
- approval items
- evidence refs

## Boundary

Creating a proposal does not:

- approve the proposal
- create canon
- create a WorkOrder
- create an AIWorkflow task
- modify source files
- commit or push

Decisions are recorded separately under:

```text
_Docs/AIWorkflow/Studio/Decisions/
```
