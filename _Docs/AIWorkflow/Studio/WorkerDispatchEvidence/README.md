# Studio Worker Dispatch Evidence

This folder stores durable evidence generated by bounded Studio Worker Dispatch
runner slices.

## E.2 Safe Smoke Boundary

Goal E.2 may write only safe smoke evidence for this allowlisted route:

```text
profile: validation
executor: hermes_safe_smoke
command_id_or_runner_route: studio.validation.report
```

The safe smoke runner validates a stored `worker_dispatch.v1` request record,
writes a deterministic evidence JSON artifact, updates that Worker Dispatch
with safe-smoke runner refs, and links a generated Result Review.

It must not:

- start PC Runner
- start Codex or local arbitrary execution from Studio
- dispatch build/test commands as a worker
- edit game source or game data
- change Backlog or ActiveTask state
- accept, reject, close, or mark done an Execution Request
- commit or push

Validation tests may use `_Temp/AIWorkflowStudio/worker_dispatch_evidence/`
overrides. Durable evidence for real E.2 smoke records belongs here.
