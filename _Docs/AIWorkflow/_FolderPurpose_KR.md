# 폴더 용도: AIWorkflow

## 목적

이 폴더는 저장소의 AI Orchestrator 워크플로우에 대한 기준 문서를 보관한다.

워크플로우 규칙, 역할 정의, 승인 게이트, 도구 라우팅 규칙, 작업 템플릿, 검토 및 검증 기준, 활성 작업 상태, 프로젝트 프로필, 프롬프트 템플릿, 워크플로우 전용 작업 요청 문서를 이 폴더에 둔다.

## 여기에 둘 문서

- AI Orchestrator protocol 문서
- Workflow scope와 운영 규칙
- Agent role 정의
- Human approval gate 규칙
- Tool routing 규칙
- Review와 validation 규칙
- AIWorkflow 작업 템플릿과 작업 요청서
- Workflow에서 사용하는 프로젝트 프로필 문서
- Workflow 문서의 한국어 필수 읽기 요약본

## 여기에 두지 않을 것

- 게임 소스 코드
- AIWorkflow 운영과 직접 관련 없는 게임 기획 문서
- 런타임 게임 시스템 아키텍처 문서
- 완료된 조사 또는 수정 작업의 Dev Log
- Workflow 실행 중 생성되는 런타임 산출물
- 로컬 머신 설정
