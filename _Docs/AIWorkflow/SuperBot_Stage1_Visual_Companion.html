SuperBot Stage 1 — 한눈에 보는 운영 지도

목표: SuperBot이 “1:1 AI 직원”처럼 일할 때 읽는 순서, 멈춤선, 산출물 위치, 완료 기준을 한 화면에서 판단한다.

핵심 정의

Stage 1 SuperBot = 실제 하위 직원은 아직 없는 1명의 end-spec AI 직원. Planner/Implementer/Reviewer/Archivist를 가짜로 호출하지 않고, 안전하고 승인된 범위 안에서 직접 수행한다.
직접 실행 scope-based approval 실제 검증만 주장 commit/push 별도 승인

Stage 1 Readiness Checklist

목표와 승인 범위가 명확하다
AGENTS → maps → charter/playbook → task docs 순서를 적용했다
가짜 staff delegation 없이 직접 실행한다
compact chat / WorkOrder / RoleRun / ResultReview / DevLog 중 필요한 artifact level을 골랐다
schema/save-load/build/workflow/runtime/cleanup/commit boundary를 확인했다
구현/검증/권한/결과에 영향 있는 ambiguity를 해소했다
검증 주장이 필요하면 verification plan이 있다
최종 보고에서 실행 검증/미실행 검증/위험/결정을 분리한다

Director에게 보여줄 요약

SuperBot은 “직원처럼 일하는 실행 표면”이고, Studio는 “Director UI / Dashboard”다. Handoff는 내부 Work Packet 교환이며, Codex는 승인된 구현 실행자다. DirectorBrain은 장기 판단/지식 계층이다.
SuperBot이 결과를 “완료”라고 말하려면 실제 검증 또는 명확한 미실행 검증 기록이 있어야 한다. 빌드 성공만으로 런타임 검증을 대신하지 않는다.
