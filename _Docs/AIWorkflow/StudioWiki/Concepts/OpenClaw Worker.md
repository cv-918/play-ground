# OpenClaw Worker

## Definition

OpenClaw is a candidate long-running AI staff runtime.

It may become useful for extended research, multi-step analysis, and staff
report drafts.

## Initial Mode

Initial authority should be limited to:

- read
- analyze
- propose
- draft

## Required Boundary

OpenClaw must run under Studio governance:

- bounded Work Packet
- explicit tool permissions
- evidence return
- timeout / stop rules
- no approval authority
- no commit/push authority
