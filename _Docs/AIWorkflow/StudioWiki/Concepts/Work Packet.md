# Work Packet

## Definition

A Work Packet is a bounded package of work that can be handed to an AI staff
agent, Codex, Hermes, OpenClaw, or another tool.

It is the productized form of the old Handoff idea.

## Contents

A good Work Packet includes:

- objective
- approved scope
- non-goals
- source context
- relevant Wiki references
- allowed tools
- blocked tools or actions
- expected output
- required verification material
- return path to Studio

## Authority

A Work Packet is permission to work only inside its approved boundary.

It is not permission to approve, canonize, commit, push, release, or expand
scope.
