# Context Pack

## Definition

A Context Pack is the selected memory and evidence that a worker needs before
doing a bounded job.

Easy distinction:

```text
Context Pack = what the worker needs to know
Work Packet = what the worker is allowed to do
```

## Sources

Context Packs may cite:

- external knowledge references
- Director decisions
- proposals
- rejected directions
- verification material
- source files or docs
- prior WorkOrders

## Rule

Context Pack content must keep proposal, decision, canon, and rejected material
separate.
