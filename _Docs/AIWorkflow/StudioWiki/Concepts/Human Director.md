# Human Director

## Definition

The Human Director is the owner of product direction, creative judgment,
approval authority, and final acceptance.

The Human Director should not have to micromanage every implementation step.
The normal expectation is:

```text
state direction -> review options -> approve direction/scope -> review results
```

## Must Decide

The Human Director decides:

- which direction is accepted
- which proposal becomes official
- which risks are acceptable
- which work scope is approved
- whether completion is accepted
- whether to commit/push/release

## Should Not Need To Decide

The Human Director should not need to inspect raw internal records unless
something is unclear or broken.
