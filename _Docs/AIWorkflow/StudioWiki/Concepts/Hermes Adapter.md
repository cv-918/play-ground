# Hermes Adapter

## Definition

Hermes is the planned browser and web-work adapter for Studio.

It is useful for web research, browser QA, page inspection, screenshots, and
external web tool experiments.

## Authority

Hermes may collect and summarize.

Hermes must not:

- approve direction
- canonize setting
- edit local source/data
- commit/push
- run unbounded browsing without approval

## Studio Input

Hermes should receive a Work Packet and Context Pack, not a vague open-ended
request.
