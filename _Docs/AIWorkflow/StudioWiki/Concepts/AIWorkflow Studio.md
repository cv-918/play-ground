# AIWorkflow Studio

## Definition

AIWorkflow Studio is the Human Director control plane for the personal AI
development studio.

It is not the main implementation worker and not a generic chatbot.

Studio is responsible for:

- collecting Director intent
- turning broad agendas into Director Briefs
- organizing advisory discussion
- surfacing decisions that need human judgment
- preparing WorkOrders and Work Packets
- linking outputs to Director decisions, reference records, verification material,
  and optional external knowledge references

## Authority

Studio can present options and prepare records.

Only the Human Director can approve:

- official project direction
- canon / official setting
- source or data modification scope
- completion decisions
- commit, push, release, or deployment
