# Folder Purpose: _Docs

## Purpose

This folder stores durable project documentation that should live at the repository level.

Use this folder for long-lived documents that describe the project, its architecture, game design, systems, and AI-assisted workflow. These documents should support planning, review, implementation, validation, and future maintenance.

## Belongs Here

- Repository-level documentation
- Architecture documents
- Game design documents
- System behavior documents
- AI workflow and orchestration documents
- Stable reference material used across tasks

## Does Not Belong Here

- Source code
- Build artifacts
- Temporary runtime files
- Local machine configuration
- Dev logs for completed or investigative work
- Project files that belong under `PlayGround/`

## Related Folders

- `_Docs/AIWorkflow/`
- `_Docs/Architecture/`
- `_Docs/GameDesign/`
- `_Docs/Systems/`
- `_DevLog/`
- `PlayGround/`
