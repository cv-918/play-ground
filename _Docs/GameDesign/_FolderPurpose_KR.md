# 폴더 용도: GameDesign

## 목적

이 폴더는 프로젝트의 게임 기획 문서를 보관한다.

플레이어가 직접 경험하는 규칙, 콘텐츠 설계, 메커닉, 성장 구조, 캐릭터, 적, NPC, 맵, 상호작용, 밸런스 의도처럼 게임이 어떤 느낌과 플레이 경험을 제공해야 하는지 정의하는 자료를 이 폴더에 둔다.

## 여기에 둘 문서

- Gameplay concept 문서
- 캐릭터, 적, NPC, faction 설계
- 맵, 씬, 지역 설계
- 전투, 이동, 상호작용, 성장 설계
- 아이템, 퀘스트, 보상, 경제 설계
- 밸런스 의도와 tuning note
- 플레이어 경험 목표

## 여기에 두지 않을 것

- 런타임 아키텍처 문서
- 소스 코드 구현 세부사항
- AIWorkflow process 문서
- 완료된 FixLog 또는 WorkLog
- `PlayGround/` 아래에 있어야 하는 원본 게임 데이터 파일
- 임시 작업 요청 문서
