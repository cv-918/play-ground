# Folder Purpose: GameDesign

## Purpose

This folder stores game design documentation for the project.

Use this folder for player-facing rules, content design, mechanics, progression, characters, enemies, NPCs, maps, interactions, balance intent, and other design material that defines what the game should feel like and how it should play.

## Belongs Here

- Gameplay concept documents
- Character, enemy, NPC, and faction design
- Map, scene, and area design
- Combat, movement, interaction, and progression design
- Item, quest, reward, and economy design
- Balance intent and tuning notes
- Player experience goals

## Does Not Belong Here

- Runtime architecture documents
- Source code implementation details
- AIWorkflow process documents
- Completed fix logs or work logs
- Raw game data files that belong under `PlayGround/`
- Temporary task request documents

## Related Folders

- `_Docs/Architecture/`
- `_Docs/Systems/`
- `_DevLog/WorkLog/`
- `PlayGround/`
