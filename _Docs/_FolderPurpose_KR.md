# 폴더 용도: _Docs

## 목적

이 폴더는 저장소 수준에서 오래 유지되어야 하는 프로젝트 문서를 보관한다.

프로젝트, 아키텍처, 게임 기획, 시스템, AI 보조 워크플로우를 설명하는 장기 문서를 이 폴더에 둔다. 이 문서들은 계획, 검토, 구현, 검증, 향후 유지보수를 지원해야 한다.

## 여기에 둘 문서

- 저장소 수준 문서
- 아키텍처 문서
- 게임 기획 문서
- 시스템 동작 문서
- AI workflow와 orchestration 문서
- 여러 작업에서 안정적으로 참조할 자료

## 여기에 두지 않을 것

- 소스 코드
- 빌드 산출물
- 임시 런타임 파일
- 로컬 머신 설정
- 완료 작업 또는 조사 작업의 Dev Log
- `PlayGround/` 아래에 있어야 하는 프로젝트 파일
