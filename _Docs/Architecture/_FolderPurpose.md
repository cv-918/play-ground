# Folder Purpose: Architecture

## Purpose

This folder stores architecture-level documentation for the game project.

Use this folder to describe long-term structure, responsibility boundaries, ownership rules, lifecycle design, data flow, rendering constraints, component relationships, and other decisions that shape how the project should be maintained and extended.

## Belongs Here

- Final-form architecture notes
- Reduced-scope architecture plans
- Responsibility boundaries between systems
- Component and service ownership rules
- Runtime lifecycle design
- Data flow and dependency diagrams
- Architectural decision records
- Migration considerations, such as future Unity migration context

## Does Not Belong Here

- Task-specific implementation logs
- Temporary notes that belong in `_DevLog/WorkLog/`
- Game balance or narrative design documents
- Low-level source code comments copied into Markdown
- AIWorkflow process rules
- Build artifacts or generated files

## Related Folders

- `_Docs/Systems/`
- `_Docs/GameDesign/`
- `_Docs/AIWorkflow/`
- `_DevLog/WorkLog/`
- `PlayGround/`

## Korean Summary

이 폴더는 게임 프로젝트의 장기 아키텍처 문서를 보관하는 위치입니다.
