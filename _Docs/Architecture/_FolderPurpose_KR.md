# 폴더 용도: Architecture

## 목적

이 폴더는 게임 프로젝트의 아키텍처 수준 문서를 보관한다.

장기 구조, 책임 경계, 소유권 규칙, 생명주기 설계, 데이터 흐름, 렌더링 제약, 컴포넌트 관계, 프로젝트의 유지보수와 확장 방식을 결정하는 설계 내용을 이 폴더에 둔다.

## 여기에 둘 문서

- Final-form architecture notes
- Reduced-scope architecture plans
- 시스템 사이의 책임 경계
- 컴포넌트와 서비스의 소유권 규칙
- 런타임 생명주기 설계
- 데이터 흐름과 dependency diagram
- Architecture decision record
- 향후 Unity migration 같은 전환 고려 사항

## 여기에 두지 않을 것

- 작업별 구현 로그
- `_DevLog/WorkLog/`에 있어야 하는 임시 조사 메모
- 게임 밸런스 또는 내러티브 기획 문서
- 소스 코드 주석을 그대로 복사한 저수준 설명
- AIWorkflow process 규칙
- 빌드 산출물 또는 생성 파일
