# Folder Purpose: Handoff Guide

## Purpose

This folder stores user-facing guide documents for the AI Role Handoff System.

Use this folder for durable HTML or other rendered guides intended for the human developer.

## Belongs Here

- Handoff user guides
- Human-readable operation guides
- Rendered or self-contained guide artifacts

## Does Not Belong Here

- Handoff Packets
- Role routine source documents
- Scanner reports
- Status update records
- Runtime artifacts
- Source code
