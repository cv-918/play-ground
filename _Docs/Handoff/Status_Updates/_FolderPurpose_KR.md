# 폴더 용도: Handoff Status Updates

## 목적

이 폴더는 Handoff 문서/상태 갱신 기록용 템플릿과 지원 문서를 보관한다.

런타임 큐가 아니며 자동화 스크립트를 담는 위치도 아니다.

## 여기에 둘 것

- 상태 갱신 기록 템플릿
- 상태 갱신 정책 메모
- 명시적으로 승인된 경우의 문서-only 상태 갱신 기록 예시

## 여기에 두지 않을 것

- 자동화 스크립트
- 스케줄 작업 정의
- Packet manifest
- 소스 코드
- 게임플레이 데이터
- 런타임 산출물
- 빌드 또는 테스트 출력
- Git 자동화

## 안전 경계

상태 갱신 기록은 Handoff 문서 변경을 설명한다.

소스 코드, 데이터, 런타임 동작, 빌드, 커밋, 푸시 작업을 승인하지 않는다.
