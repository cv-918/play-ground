# Folder Purpose: Handoff Status Updates

## Purpose

This folder stores templates and support documents for Handoff document/status update records.

It is not a runtime queue and it does not contain automation scripts.

## Belongs Here

- Status update record templates
- Status update policy notes
- Examples of document-only status update records, when explicitly approved

## Does Not Belong Here

- Automation scripts
- Scheduled job definitions
- Packet manifests
- Source code
- Gameplay data
- Runtime artifacts
- Build or test outputs
- Git automation

## Safety Boundary

Status update records describe Handoff document changes.

They do not approve source code, data, runtime behavior, build, commit, or push work.
