# 폴더 용도: Handoff Scanner

## 목적

이 폴더는 AI Role Handoff System의 읽기 전용 스캐너 설계 지원 문서와 보고서 템플릿을 보관한다.

스캐너는 Handoff 상태를 읽고 큐, 승인 대기, 막힌 작업, 정합성 문제를 보고하는 향후 보조 동작이다. 저장소 파일은 변경하지 않는다.

## 여기에 둘 것

- 읽기 전용 스캔 보고서 템플릿
- 역할별 조회 예시
- 스캐너 출력 형식 안내
- 스캐너 안전 규칙

## 여기에 두지 않을 것

- 자동화 스크립트
- 스케줄 작업 정의
- 이후 Phase에서 명시적으로 승인하지 않은 생성된 스캔 보고서
- Packet manifest
- 소스 코드
- 런타임 산출물
- Git 자동화

## 안전 경계

Phase 5 스캐너 동작은 읽기 전용이다.

파일 쓰기, 상태 갱신, claim, 승인 기록, 빌드/테스트 실행, 커밋, 푸시는 허용하지 않는다.
