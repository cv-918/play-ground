# 폴더 용도: Handoff

## 목적

이 폴더는 역할별 채팅 또는 담당자 간 작업 전달을 위한 공용 교환소입니다.

기획자, 개발자, 아트, 리뷰어, QA 담당자처럼 서로 다른 역할이 작업을 넘길 때 필요한 기획서, 리소스 안내, 구현 요청, 리뷰 요청, QA 요청, 완료 노티를 여기에 둡니다.

이 구조는 기존 AIWorkflow를 대체하지 않습니다. 기존 워크플로우 위에 역할 간 전달물을 정리하기 위해 추가로 사용하는 공간입니다.

## 여기에 둘 것

- 역할 간 업무 전달 문서
- 개발/아트/리뷰/QA로 넘길 기획 브리프
- 리소스 전달 안내
- 구현 요청 문서
- 리뷰 요청과 리뷰 결과
- QA 요청과 QA 결과
- 개발 완료 노티
- 관련 파일, 커밋, 작업 요청서, Dev Log 링크

## 여기에 두지 않을 것

- AIWorkflow 운영 규칙의 원본 문서
- 런타임 소스 코드
- 임시 실행 산출물
- 로컬 머신 설정
- 프로젝트 리소스 폴더나 외부 저장소에 있어야 할 대용량 원본 리소스
- `_DevLog/`에 남겨야 하는 완료 작업 이력

## 하위 폴더

- `Intake/`: 아직 분류되지 않은 신규 전달물
- `Packets/`: manifest를 포함한 구조화된 Handoff Packet 폴더
- `Role_Routines/`: 역할별 Handoff 작업 루틴
- `Scanner/`: 읽기 전용 스캐너 보고 형식과 요청 예시
- `Status_Updates/`: 문서-only Handoff 상태 갱신 기록 템플릿
- `Guide/`: 사용자용 Handoff 가이드 문서
- `Planning/`: 기획/디자인 전달 문서
- `Resources/`: 리소스 전달 안내와 사용 조건
- `Implementation/`: 구현 요청 전달 문서
- `Review/`: 리뷰 요청과 리뷰 결과
- `QA/`: QA 요청, 테스트 시나리오, QA 결과
- `Done/`: 완료 노티와 전달 완료 보고
- `Archive/`: 비활성 또는 대체된 전달 문서

## 기존 워크플로우와의 관계

- `_Docs/AIWorkflow/`는 AI 작업 절차와 운영 규칙의 기준입니다.
- `_DevLog/`는 완료된 작업, 조사, 수정, 회고 기록을 남기는 위치입니다.
- `_Temp/`는 추적하지 않는 임시 실행 산출물 위치입니다.
- `_Docs/Handoff/`는 역할 간 전달물이 오가는 공용 저장공간입니다.
