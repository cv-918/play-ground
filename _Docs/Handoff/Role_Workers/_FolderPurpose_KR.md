# 폴더 용도: Handoff Role Workers

이 폴더는 Handoff Queue를 수거하는 역할 채팅 또는 미래의 역할 직원 자동화를 위한 계약과 템플릿을 보관한다.

이 폴더에 둘 것:

- 역할 직원 intake 규칙
- Queue 수거 계약
- Intake 결정 템플릿
- 역할 직원 하네스 규칙
- 미래의 낮은 위험 역할 자동화 경계

이 폴더에 두지 말 것:

- Handoff Packet
- 생성 Queue
- 생성 Dashboard 파일
- 게임 소스 코드
- 게임플레이 JSON
- 자동화 스크립트
- commit 또는 push 자동화

여기의 역할 직원 문서는 소스, JSON, 에셋, 빌드 설정, approval evidence, Git 이력 수정 권한을 부여하지 않는다.
