# Folder Purpose: Role Worker Harness

This folder stores test and check documents for verifying that a role chat or future role-worker automation follows the Handoff Role Worker Intake Contract.

Use this folder for:

- contract check protocol
- contract check templates
- blind test case templates
- run report templates
- role readiness evidence

Do not use this folder for:

- Handoff Packet content
- generated role Queues
- game source or data
- recurring automation definitions
- role-worker implementation automation

Harness documents measure whether a role is ready to work. They do not grant permission to execute risky work.
