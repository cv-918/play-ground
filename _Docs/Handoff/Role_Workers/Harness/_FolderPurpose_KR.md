# 폴더 용도: Role Worker Harness

이 폴더는 역할 채팅 또는 미래의 역할 직원 자동화가 Handoff Role Worker Intake Contract를 따르는지 검증하는 테스트와 체크 문서를 보관한다.

이 폴더에 둘 것:

- 계약 확인 프로토콜
- 계약 확인 템플릿
- 블라인드 테스트 케이스 템플릿
- 실행 리포트 템플릿
- 역할 준비 상태 증거

이 폴더에 두지 말 것:

- Handoff Packet 내용
- 생성 역할 Queue
- 게임 소스 또는 데이터
- 반복 자동화 정의
- 역할 직원 구현 자동화

하네스 문서는 역할이 작업할 준비가 되었는지 측정한다. 위험 작업 실행 권한을 부여하지 않는다.
