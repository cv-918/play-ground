## 기대 답변 체크리스트

- [ ] `WaitingUserApproval`은 사용자 결정이 필요하다고 말한다.
- [ ] 작업 전에 Intake Decision이 필요하다고 말한다.
- [ ] 명시 승인 없는 금지 행동을 말한다.
