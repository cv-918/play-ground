# Folder Purpose: Role Worker Harness Runs

This folder stores concrete run reports produced by the Role Worker Harness.

Use this folder for:

- contract check results
- blind scenario results
- intake decision review results
- failed role readiness evidence
- recovery notes before real work assignment

Do not use this folder for:

- Handoff Packet source documents
- generated Queues
- game source or data
- role-worker automation scripts
- approval evidence

Harness runs are readiness evidence only. They do not approve implementation, data, runtime, build, Git, or completion actions.
