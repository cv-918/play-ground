# 폴더 용도: Role Worker Harness Runs

이 폴더는 Role Worker Harness가 생성한 실제 실행 리포트를 보관한다.

이 폴더에 둘 것:

- 계약 확인 결과
- 블라인드 시나리오 결과
- Intake Decision 리뷰 결과
- 역할 준비 상태 실패 증거
- 실제 작업 배정 전 복구 메모

이 폴더에 두지 말 것:

- Handoff Packet 원본 문서
- 생성 Queue
- 게임 소스 또는 데이터
- 역할 직원 자동화 스크립트
- approval evidence

하네스 실행 기록은 준비 상태 증거일 뿐이다. 구현, 데이터, 런타임, 빌드, Git, 완료 처리 권한을 승인하지 않는다.
