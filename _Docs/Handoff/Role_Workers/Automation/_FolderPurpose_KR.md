# 폴더 용도: Role Worker Automation

이 폴더는 미래의 낮은 위험 역할 직원 자동화 run report와 자동화 전용 메모를 보관한다.

이 폴더에 보관하는 것:

- 낮은 위험 역할 직원 자동화 run report
- 건너뛴 후보 요약
- 막힌 후보 요약
- 자동화 감사 메모

이 폴더에 보관하지 않는 것:

- Handoff Packet
- Supervisor가 생성한 Dashboard, Queue, Violation 파일
- 게임 소스 코드
- gameplay JSON
- asset 파일
- 자동화 스크립트
- approval evidence
- commit 또는 push 자동화

이 폴더는 자동화 실행 또는 생성 권한을 부여하지 않는다. 실제 recurring automation 생성은 별도 사용자 승인이 필요하다.
