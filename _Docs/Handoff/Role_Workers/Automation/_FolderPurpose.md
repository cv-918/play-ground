# Folder Purpose: Role Worker Automation

This folder stores future low-risk Role Worker automation run reports and automation-specific notes.

Use this folder for:

- low-risk role-worker automation run reports
- skipped candidate summaries
- blocked candidate summaries
- automation audit notes

Do not use this folder for:

- Handoff Packets
- generated Supervisor Dashboard, Queue, or Violation files
- game source code
- gameplay JSON
- asset files
- automation scripts
- approval evidence
- commit or push automation

This folder does not grant permission to run or create automation. Actual recurring automation creation requires separate human approval.
