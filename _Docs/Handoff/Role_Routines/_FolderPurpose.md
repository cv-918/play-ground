# Folder Purpose: Role Routines

## Purpose

This folder stores role-specific operating routines for the AI Role Handoff System.

Each routine explains how a role chat should inspect Handoff, claim work, plan, request approval, produce results, and hand work to the next role.

## Belongs Here

- Role routine documents
- Shared role routine overview
- Role-specific Handoff usage rules
- Role-specific stop conditions and output expectations

## Does Not Belong Here

- Handoff Packet instances
- Source code
- Runtime artifacts
- Automation scripts
- Completed work records that belong in `_DevLog/`

## Required Reading For Role Chats

Before using a role routine, read:

- `../Handoff_System_Principles.md`
- `../Handoff_Packet_Spec.md`
- `Role_Routine_Overview.md`
- The routine for the current role
