# 폴더 용도: Role Routines

## 목적

이 폴더는 AI Role Handoff System에서 각 역할 채팅이 따라야 하는 작업 루틴을 보관한다.

각 루틴은 역할 채팅이 Handoff를 확인하고, 작업을 수거하고, 계획을 세우고, 승인을 요청하고, 결과를 남기고, 다음 역할로 넘기는 방법을 설명한다.

## 여기에 둘 것

- 역할별 루틴 문서
- 공통 역할 루틴 개요
- 역할별 Handoff 사용 규칙
- 역할별 중단 조건과 산출물 기준

## 여기에 두지 않을 것

- 실제 Handoff Packet
- 소스 코드
- 런타임 산출물
- 자동화 스크립트
- `_DevLog/`에 있어야 하는 완료 작업 기록
