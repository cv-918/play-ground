** 스테이지 액터(몬스터 또는 오브젝트) 스폰 루틴**
1. 스테이지 매니저의 Update 가 수행되면서 스테이지 타이머 측정
-> 스테이지 매니저의 Update 호출해야함
-> 스테이지 매니저에 타이머 측정 기능이 있어야 함

2. 타이머에 의해 조건이 충족되는 경우 스테이지 매니저가 씬의 오브젝트 매니저에 스폰 요청
-> 생성 대상 액터에 대한 조건이 있어야 함(타이머, 웨이브 형태 등)
-> 오브젝트 매니저에 요청할 수 있어야 함(오브젝트 매니저를 참조하고 있거나, 브로드 캐스팅이 필요함)

3. 오브젝트 매니저는 요청받은 오브젝트를 스폰

[ Bullet 시스템 설계 ]
- Bullet은 Unit이 발사하는 투사체입니다. Bullet은 Unit의 공격력과 이동 속도 등의 정보를 가지고 있으며, 일정 시간 동안 이동하다가 사라집니다. Bullet은 충돌 판정을 위해 Collider를 가지고 있으며, 다른 Collider와 충돌할 때 데미지를 입힐 수 있습니다.
- Bullet은 Unit의 공격 패턴에 따라 다양한 형태로 발사될 수 있습니다. 예를 들어, 직선으로 발사되는 일반적인 총알, 일정 각도로 퍼지는 산탄, 플레이어를 추적하는 유도탄 등이 있을 수 있습니다. Bullet의 이동 방식과 충돌 판정 로직은 Bullet 클래스에서 구현됩니다.
- Bullet의 관리는 Object Manager에서 이루어집니다. Object Manager는 Bullet을 생성하고, 업데이트하며, 일정 시간이 지나거나 충돌이 발생하면 Bullet을 제거하는 역할을 합니다. Bullet의 생성과 제거는 Unit의 공격 패턴과 게임의 상황에 따라 동적으로 이루어집니다.

- 발사 로직을 누가 갖고있어야 하는가?
=> '발사'에 대한 로직 자체는 Enemy가 갖게끔 했다
=> ExpDust 외에도 다양한 적이 생길 경우에도 '투사체 발사'자체는 Enemy의 기능이다.
=> 단, Player도 투사체를 발사할 수 있도록 확장될 수도 있다(스킬, 아이템 등 뭐가 추가될지 모르기 때문)
=> 그럴 경우에는 Unit 투사체 발사 로직을 Unit으로 이관


[ 어트리뷰트 노드 설계 ]
- 어트리뷰트 노드는 캐릭터의 능력치와 추가 패시브 스킬 등을 관리하는 개념
- 아직 이 부분에 대한 상세, 세부 기획이 나온 것은 아니기 때문에 스켈레톤 버전에서는 캐릭터의 능력치 추가만 만들어두자

* 각 노드가 가져야할 것들
- 노드의 아이디
- 노드의 이름
- 노드의 아이콘
- 노드의 설명
- 노드의 레벨(현재, 최대)
- 노드의 등급
- 노드의 종류(능력치, 패시브 스킬 등)
- 노드의 연결 정보(이전 노드, 다음 노드)
- 노드의 해금 정보
- 노드의 해금 조건
- 노드의 비용 정보
- 노드의 효과(능력치 증가량, 패시브 스킬 효과 등)
- 노드의 위치정보(위치 정보를 기록할 것인가? 패턴을 갖추고 기존 정보들을 조합해 위치가 알아서 잡히게끔 할 것인가?)

-- 노드의 데이터는 '노드별' 데이터가 있고 노드의 '레벨별' 데이터가 있어야 한다.
-- 어트리뷰트 노드를 통해 제어할 능력치의 종류를 먼저 설정하고 각 능력치마다 id를 부여해서 노드 정보에 편입시켜야 한다
-- 임시로 디자인 해보자면
	패시브 : 각성(세계관의 시작으로 얻을 수 있는 기본 노드, 먼지를 모을 수 있게 됨)
	능력치 : 공격 범위 크기
	능력치 : 공격력
	능력치 : 공격속도
	능력치 : 이동속도

-- 어트리뷰트 노드와 스킬 노드는 각 노드 당 단계를 나타내는 JSON을 따로 두자. JSON 파일의 개수는 많아지겠지만, 보기는 더 편리할 것

어트리뷰트 발견
캐릭터 종류를 해금할 때마다 이전에 보이지 않던 어트리뷰트 노드가 추가로 보이게 되는 것

어트리뷰트 해금
습득 조건을 충족해서 어트리뷰트 노드의 Disable 상태가 해제되는 것

어트리뷰트 습득
어트리뷰트 포인트를 투자해서 노드의 레벨을 0 -> 1로 올리는 것
