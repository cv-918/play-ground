# Fix Log - 2026-04-12

## 작업 목적
`ApplyVideoMode` 적용 이후, `OutGame` 씬의 월드/네비메시/UI 레이아웃이 해상도 변경을 따라가도록 정리.

## 핵심 변경 요약
- 영상 설정 적용 성공 시점을 감지하기 위해 `VideoSettingsManager`에 `AppliedRevision` 추가.
- `OutGameScene`에서 revision 변화를 감지하면 1회만 viewport 변경 처리.
- viewport 변경 시:
  - `Background` 크기/네비메시 갱신
  - 카메라 viewport, world bounds 재설정
  - 생성된 `OutGame` 뷰들에 `OnViewportChanged()` 전파

## UI 대응 방식
- `WidgetBase`에 `OnViewportChanged()` 훅 추가.
- 각 뷰는 필요한 레이아웃만 갱신:
  - `OutGameMainView`: 우상단 버튼 라인 재배치
  - `OutGameOptionView`: 캐시 무효화 후 레이아웃/텍스트/그리드 갱신
  - `OutGameAttributeView`: `RETURN` 버튼 + 스킬 `Grid` 재배치
  - `OutGameExitView`: 팝업/버튼 중앙 재정렬
  - `AttributeNodeTree`: 화면 중심 변화량(delta)만큼 전체 노드 이동
