# 스킬 시스템 재정비 기획서 v2 (확정본)

## 0. 문서 목적

본 문서는 현재 `SkillJsonInfo` 및 스킬 JSON 데이터를 기준으로,
플레이어 스킬 4종의 **실제 구현 기준 명세**를 정의한다.

본 문서는 다음 목적에 사용된다.

* 현재 코드와 스킬 의도 일치 여부 검증
* 누락된 판정 / 상태 / 실행 구조 식별
* 구현 기준 통일
* 데이터 해석 일관성 확보

---

## 1. 공통 데이터 해석 규칙

### 1-1. 범위 / 크기

* `area_of_effect_` = Radius
* `proj_size_` = 충돌체 Radius

---

### 1-2. 피해 계산

```text
최종 피해 = (공격력 × damage_multiplier_) + flat_damage_
```

현재 스킬은 모두 multiplier = 0 → flat_damage만 사용

---

### 1-3. 방향 기준

* 모든 방향성 스킬은 **현재 바라보는 방향 기준**

---

### 1-4. 시전 규칙

#### 즉시 시전

* 모션 없음
* 입력 즉시 발동

#### 비즉시 시전

* 시전 시간 존재
* 이동 입력 차단
* 기존 속도 유지 (관성 유지)

---

### 1-5. 상태 정의

#### Root

* 자발 이동 차단
* 넉백 허용
* 공격/회전 가능

#### Invincible

* 모든 피해 무시
* 넉백 면역
* 겹침 허용

---

### 1-6. 투사체 lifetime

우선순위:

1. 화면 밖 이탈
2. 명시적 제거
3. lifetime 만료

→ lifetime은 failsafe

---

## 2. 스킬 실행 구조

필수 실행 타입:

1. 직선 관통 투사체
2. 확장형 디버프
3. 자기 버프
4. 공전 위성

필수 분리:

* SkillData
* SkillRuntime
* Casting
* Projectile
* Buff
* Debuff
* Orbiting

---

## 3. 스킬 상세

---

### Skill 0. 먼지 돌풍

#### 타입

* 비즉시 시전
* 관통 투사체

#### 흐름

1. 캐스팅
2. 이동 입력 차단 (관성 유지)
3. 시전 완료 → 투사체 생성

#### 투사체

* 속도: 1000
* 반경: 40
* lifetime: 30
* 방향: 바라보는 방향

#### 판정

* 관통
* 동일 대상 1회 타격

#### 피해

* flat_damage = 12

---

### Skill 1. 부식

#### 타입

* 즉시 시전
* 확장형 디버프

#### 흐름

1. 즉시 발동
2. 0.5초 동안 범위 확장
3. collision enter 대상 확정
4. 디버프 적용

#### 디버프

* duration: 3초
* tick: 1초
* 총 3회
* 즉시 피해 없음

#### 상태

* Root (이동만 차단)

---

### Skill 2. 다크사이트

#### 타입

* 즉시 시전
* 자기 버프

#### 효과

* duration: 1.5초
* 완전무적
* 넉백 면역
* 이동속도 +50%
* 현재 속도 = 최대속도

---

### Skill 3. 보풀 위성

#### 타입

* 비즉시 시전
* 공전 위성

#### 흐름

1. 캐스팅
2. 위성 2개 생성
3. 4초 유지

#### 위성

* 반경: 120
* 개수: 2
* 반경: 30
* 공전

#### 피해

* flat_damage = 8
* 대상별 0.5초 간격

#### 추가 효과

* 충돌 시 넉백
* 기존 넉백 시스템 사용

#### 접근 차단 의미

* Damage + Knockback
* Path blocking 없음

## 5. 구현 검증 기준

### 구조

* Skill / Runtime / Execution 분리 여부
* 스킬별 if/switch 제거 여부

---

### 판정

* 투사체 1회 타격 제한
* 부식 확장 + enter 판정
* 보풀 위성 hit interval 존재

---

### 상태

* Root / Invincible 분리 여부

---

### 시전

* 즉시 / 비즉시 구분
* 이동 입력 차단 vs 관성 유지
