[ 어트리뷰트 시스템 설계 ]
- 어트리뷰트 노드는 캐릭터의 능력치와 추가 패시브 스킬 등을 획득할 수 있는 컨텐츠.
- 플레이어는 자원을 투자하여 노드를 해금하고 레벨을 올릴 수 있음.
- 노드 간에는 연결 정보가 존재하여 플레이어가 전략적으로 노드를 선택할 수 있도록 함.
- 어트리뷰트 시스템은 캐릭터의 성장과 커스터마이징에 중요한 역할을 하며, 플레이어에게 다양한 선택지를 제공.

* 어트리뷰트 노드의 종류
- 능력치 노드: 공격력, 방어력, 이동속도 등 캐릭터의 기본 능력치를 증가시키는 노드
- 패시브 스킬 노드: 특정 조건에서 발동하는 추가 효과를 제공하는 노드(예: 공격 시 일정 확률로 추가 데미지, 적을 처치할 때마다 체력 회복 등)
- 특수 노드: 특수한 효과를 제공하는 노드(예: 노드 습득 시 새로운 드롭 아이템이 추가되는 노드, 특정 스테이지에서 보너스 효과를 제공하는 노드 등)

* 어트리뷰트 노드의 진행 단계
- 발견 : 캐릭터 종류를 해금할 때마다 이전에 보이지 않던 어트리뷰트 노드가 추가로 보이게 되는 것
- 해금 : 습득 조건을 충족해서 어트리뷰트 노드의 Disable 상태가 해제되는 것
- 습득 : 자원을 투자해서 노드의 레벨을 0 -> 1로 올리는 것
- 강화 : 자원을 투자해서 노드의 레벨을 1 -> 2 이상으로 올리는 것

* 어트리뷰트 노드의 상태
- Hidden : 발견되지 않음 (unlock_character_id_에 해당하는 캐릭터를 획득하지 않음)
- Discovered(Locked) : 발견됐으나 비활성화됨 (unlock_character_id_에 해당하는 캐릭터를 획득했지만 노드를 습득조건이 충족되지 않음)
- Unlocked : 발견되고 활성화됨 (unlock_character_id_에 해당하는 캐릭터를 획득했고, 노드 습득조건이 충족되어 노드가 활성화된 상태)
- Acquired : 발견되고 활성화되고 습득됨 (unlock_character_id_에 해당하는 캐릭터를 획득했고, 노드 습득조건이 충족되어 노드가 활성화된 상태에서 플레이어가 해당 노드를 습득한 상태)

* 각 노드가 가져야할 것들
- 노드의 아이디
- 노드의 이름
- 노드의 아이콘
- 노드의 설명
- 노드의 레벨(현재, 최대)
- 노드의 등급
- 노드의 종류(능력치, 패시브 스킬 등)
- 노드의 연결 정보(이전 노드, 다음 노드)
- 노드의 해금 정보
- 노드의 해금 조건
- 노드의 비용 정보
- 노드의 효과(능력치 증가량, 패시브 스킬 효과 등)
- 노드의 위치정보(위치 정보를 기록할 것인가? 패턴을 갖추고 기존 정보들을 조합해 위치가 알아서 잡히게끔 할 것인가?)

-- 노드의 데이터는 '노드별' 데이터가 있고 노드의 '레벨별' 데이터가 있어야 한다.
-- 어트리뷰트 노드를 통해 제어할 능력치의 종류를 먼저 설정하고 각 능력치마다 id를 부여해서 노드 정보에 편입시켜야 한다
-- 임시로 디자인 해보자면
	패시브 : 각성(세계관의 시작으로 얻을 수 있는 기본 노드, 먼지를 모을 수 있게 됨)
	능력치 : 공격 범위 크기
	능력치 : 공격력
	능력치 : 공격속도
	능력치 : 이동속도

-- 어트리뷰트 노드와 스킬 노드는 각 노드 당 단계를 나타내는 JSON을 따로 두자. JSON 파일의 개수는 많아지겠지만, 보기는 더 편리할 것
